## Project Overview

Prime Fade Studio is a fictional South African barbershop website
designed to provide customers with information about the business,
its services, locations and appointment enquiry process.

The website consists of five main pages: Home, About Us, Services,
Enquiry and Contact.

## Website Goals and Objectives

The main goal of the website is to create a professional and
user-friendly online presence for Prime Fade Studio.

The objectives are to:

- Provide information about the barbershop.
- Display available grooming services and prices.
- Allow customers to submit an appointment enquiry.
- Provide contact information and business locations.
- Create a visually appealing and easy-to-navigate website.

## Key Features and Functionality

- Five interconnected HTML pages.
- Navigation menu across all pages.
- Appointment enquiry form.
- Service information and images.
- Contact information.
- Two business locations.
- Embedded Google Maps.
- Responsive website layout.
- CSS styling and hover effects.
