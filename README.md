## Project Overview

Prime Fade Studio is a fictional South African barbershop website
designed to provide customers with information about the business,
its services, locations and appointment enquiry process.

The website consists of five main pages: Home, About Us, Services,
Enquiry and Contact.

## Website Goals and Objectives

The main goal of the website is to create a professional and
user-friendly online presence for Prime Fade Studio.

The objectives are to:

- Provide information about the barbershop.
- Display available grooming services and prices.
- Allow customers to submit an appointment enquiry.
- Provide contact information and business locations.
- Create a visually appealing and easy-to-navigate website.

## Key Features and Functionality

- Five interconnected HTML pages.
- Navigation menu across all pages.
- Appointment enquiry form.
- Service information and images.
- Contact information.
- Two business locations.
- Embedded Google Maps.
- Responsive website layout.
- CSS styling and hover effects.

### Version 2.0 - part 2
Part 2 focused on improving the Prime Fade Studio website based on the feedback from Part 1 and applying CSS styling and responsive design.

#### Part 1 Feedback Updates

- Corrected HTML structure and formatting across the five pages.
- Updated page titles for each HTML page.
- Corrected image tags and alternative text.
- Corrected inconsistent CSS class names.
- Improved consistency across the navigation , headings and footer.
- Removed unnecessary HTML line breaks used for spacing and used CSS instead.

#### CSS Styling
- Updated the external 'style.css' stylesheet and linked it to all five HTML pages.
- Added a CSS reset using the universal selector.
- Applied consistent font family, font size, colours, margins and padding.
- Added typography styling for headings and paragraphs.
- Used Flexbox for the navigation menu.
- Added borders, border-radius and box-shadow to website sections.
- Added hover, focus, active and visited pseudo-classes.
- Styled the service cards using CSS.
- Styled the appointment enquiry form.
- Styled the contact page and embedded maps.

#### Responsive Design
- Added responsive styling using a media query and a 768px breakpoint.
- Changed the navigation layout for smaller screens.
- Changed the service cards from multiple columns to a single-column layout on smaller screens.
- Adjusted the main content width for smaller screens.
- Adjusted forms to fit smaller screens.
- Adjusted embedded Google Maps to fit smaller screens.
- Used relative units and percentage-based widths where appropriate.
- Tested the website at desktop, tablet and mobile screen sizes.

#### Part 2 Testing 
The website was tested using browser developertools at different screen sizes. The pages were checked to ensure that the navigation, images, service cards, forms, contact sections and footer remained usable on desktop, tablet and mobile screen sizes.
